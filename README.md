# Сайт-поздравление для Принцессы

Готовый одностраничный сайт (HTML/CSS/JS, без установки чего-либо).
Открой `index.html` двойным кликом — он откроется в браузере.

## Что внутри

- **Hero-блок** с поздравлением и настоящим фото.
- **«Какая ты на самом деле»** — 5 карточек с положительными чертами (работа, сила духа и т.д.), часть — с видео.
- **Фотоколлаж** — сетка из 7 карточек с реальными фото и видео.
- **«Шуточное досье»** — шуточные шкалы характеристик + 3 забавные карточки, одна — с видео.
- **Финал** — тёплое поздравление, подпись и кнопка с конфетти.

Звук у видео убран специально — автовоспроизведение в браузере всё равно требует `muted`,
а фоновая музыка из сторис могла быть защищена авторским правом.

Карточки про Диму (в «Какая ты на самом деле» и в коллаже) и шуточная карточка «Королева
вечерних покатушек» убраны по просьбе — подходящих кадров для них и так не было.

Видео в карточке «Умеешь наполняться тишиной» — это силуэт на фоне заката (контровой свет),
поэтому черты лица там не разглядеть физически, на любом кадре из этого видео. Кроп сейчас
сдвинут вверх, чтобы голову не обрезало по краю карточки.

## Если хочешь что-то поменять

- Исходные файлы `1.jpg … 7.jpg` и `1.mp4 … 4.mp4` удалены из `photos/` — там остались только
  уже обработанные версии, которые использует сайт.
- Старые SVG-плейсхолдеры (`work.svg`, `redhair.svg`, `dima.svg`, `steering-wheel.svg` и т.д.)
  остались в папке, но в `index.html` больше не используются — удалять не обязательно, не мешают.
- Обращение на сайте — «Принцесса» (заголовок, подпись на полароиде, финал), подпись в самом
  низу — «— твой рыцарь» (`index.html`, секция «Финал»).
- Хочешь добавить ещё фото в коллаж — скопируй `<figure>` в блоке `.collage` и укажи свой файл.
