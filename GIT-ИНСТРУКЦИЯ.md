# Как загрузить сайт в Git (GitHub)

Git у тебя уже установлен (`git version 2.55.0`), так что ничего ставить не нужно.
Инструкция ниже — на создание приватного репозитория на GitHub и загрузку туда папки сайта.

## 0. Важно про приватность

В сайте реальные фото и видео Алины. Если в конце включишь **GitHub Pages**, чтобы
открыть сайт по ссылке в браузере — страница станет доступна **по прямой ссылке любому**,
даже если сам репозиторий приватный (GitHub Pages так устроен). Поэтому:

- Репозиторий делай **Private**.
- GitHub Pages включай, только если тебя устраивает, что сайт будет доступен по ссылке
  всем, у кого она есть (просто предсказать адрес со стороны почти невозможно, но это
  не то же самое, что «закрыто»).
- Если нужна полная приватность — просто используй Git как бэкап/версионирование,
  а сайт отправляй Алине файлом `index.html` напрямую (как и раньше).

## 1. Создай репозиторий на GitHub

1. Зайди на [github.com](https://github.com) и войди (или зарегистрируйся).
2. Нажми **New repository** (зелёная кнопка или `+` в правом верхнем углу → *New repository*).
3. Укажи имя, например `alina-birthday`.
4. Выбери **Private**.
5. Ничего не отмечай (не добавляй README/.gitignore — они не нужны, у тебя уже есть файлы).
6. Нажми **Create repository**.
7. На открывшейся странице скопируй ссылку репозитория — она выглядит так:
   `https://github.com/твой_логин/alina-birthday.git`

## 2. Подготовь папку (один раз)

Открой терминал в папке сайта:

```bash
cd "E:\Сайт для поздравления"
git init
```

Необязательно, но рекомендую — исключить из загрузки исходники со звуком
(`*_sound.mp4`), они тяжёлые и на сайте не используются:

```bash
echo "*_sound.mp4" > .gitignore
```

## 3. Добавь файлы и сделай первый коммит

```bash
git add .
git commit -m "Сайт-поздравление для Алины"
```

Если Git спросит имя и почту (при самом первом коммите на компьютере):

```bash
git config --global user.name "Твоё имя"
git config --global user.email "твоя_почта@example.com"
```

...и повтори команду `git commit` выше.

## 4. Подключи GitHub и отправь файлы

```bash
git branch -M main
git remote add origin https://github.com/твой_логин/alina-birthday.git
git push -u origin main
```

При первом `push` браузер откроет окно входа в GitHub (или попросит токен) — просто
подтверди вход.

## 5. Проверка

Обнови страницу репозитория на GitHub — там должны появиться `index.html`, `README.md`
и папка `photos/`.

## Если потом что-то поменяешь в сайте

```bash
git add .
git commit -m "Что поменял"
git push
```

## (Опционально) Включить GitHub Pages

Settings → Pages → Source: ветка `main`, папка `/root` → Save.
Через пару минут сайт будет доступен по адресу вида
`https://твой_логин.github.io/alina-birthday/` — см. предупреждение о приватности в пункте 0.

## Если не хочешь платный хостинг с пробным периодом

Для такого сайта (просто HTML + фото/видео, без сервера и базы данных) платный хостинг
вообще не нужен — есть бесплатные варианты без ограничения по времени:

- **GitHub Pages** — см. выше, полностью бесплатно навсегда, настраивается через тот же
  репозиторий, что уже создан по этой инструкции.
- **Netlify** / **Vercel** / **Cloudflare Pages** — тоже бесплатно навсегда для такого
  сайта, загрузка проще (можно перетащить папку мышкой на сайте сервиса, без git).
  Из России доступ к ним бывает нестабильным (жалобы пользователей на блокировки у
  некоторых провайдеров) — если не откроется с первого раза, это может быть временно.

Классические российские хостинги (Timeweb, Beget, reg.ru) дают пробный период, но
короткий — обычно 10–14 дней, а не месяц, и дальше хостинг платный. Для такого сайта
это не нужно: бесплатные варианты выше решают задачу без ограничения по времени и без
оплаты.
